# 🛍️ Men Clothing Store

A **full-stack men’s wear e-commerce web application** built using the **MERN stack (MongoDB, Express.js, React, Node.js)**.  
The platform provides a smooth and modern shopping experience where users can browse products, view details, and manage their cart efficiently.

---

## 🚀 Features

### 🛒 Product Browsing
- Browse products by categories:
  - 👕 T-Shirts  
  - 👔 Shirts  
  - 👖 Jeans  
  - 👟 Shoes  
- Clean and user-friendly interface for easy navigation

---

### 🔍 Product Details
- View complete product information:
  - Images  
  - Price & discounts  
  - Description  
  - Available sizes  

---

### 🛍️ Shopping Cart
- Add products to cart  
- Update quantity or remove items  
- Real-time cart updates  

---

### 🌟 Homepage & Featured Collections
- Displays:
  - Featured products  
  - Trending collections  
  - Highlighted items  

---

### 📱 Responsive Design
- Fully responsive across:
  - Mobile 📱  
  - Tablet 💻  
  - Desktop 🖥️  

---

## 🛠 Tech Stack

- **Frontend:** React.js, CSS / Tailwind / Bootstrap  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB
